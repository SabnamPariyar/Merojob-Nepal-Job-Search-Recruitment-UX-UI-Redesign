# Merojob — Visual Design System

A Nepal-aware, bilingual, accessible visual language for job-seeker and recruiter journeys.

## Foundations

| Token | Value | Role |
| --- | --- | --- |
| Himalayan Ink | `#29234D` | Headers, text and depth |
| Action Violet | `#6E56C9` | Primary calls to action |
| Lavender | `#A38CEF` | Highlight and illustration |
| Soft Cloud | `#F7F5FC` | Application canvas |
| Progress Green | `#168A77` | Completion and positive statuses |
| Border | `#E7E3F0` | Input and card boundaries |

## Typography

- **Manrope:** English headings and display text.
- **DM Sans:** Latin UI labels, body copy and forms.
- **Noto Sans Devanagari:** Nepali labels, headings, and other translated interface content.
- Display scale 70px; headings 42/27px; body 16px; routine labels 14px or larger.

## Layout

Responsive 12-column grid, content width 1460px, 8-point spacing rhythm, 11px button/input radius, and 19px content-card radius.

## Components

Search and location filters · Sector filter · Job listing cards · Save control · Application stage cards · Candidate profile form · Progress bar · Employer shortlisting cards · Buttons · Status chips · Feedback toast · Responsive navigation.

## Interaction principles

- Make location and salary visible in every job card.
- Pair statuses with clear words, not color alone.
- Provide a safe reset for simulated actions.
- Use descriptive control labels and keyboard-focus indicators.
- Preserve natural Nepali typesetting rather than forcing Latin spacing rules.

## Moodboard

Nepal's mountains, urban life, professional collaboration and clean contemporary architecture inform the visual direction. The imagery in the interactive experience is from externally hosted Unsplash references and is not original photography by Sabnam.
